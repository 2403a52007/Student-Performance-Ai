# 🎓 Student Performance Prediction using AI

An AI-powered web application that predicts student performance based on academic input parameters using Machine Learning. The application provides instant predictions through an intuitive Streamlit interface, helping demonstrate the practical use of AI in educational analytics.

## 🌐 Live Demo

🔗 https://student-performance-ai-jvba3ljx7nbwrc4thrpkzg.streamlit.app/

---

## 📖 Project Overview

This project leverages Machine Learning to estimate student performance based on key academic factors. It demonstrates the complete workflow of building an AI application, from data preprocessing and model training to deployment through an interactive web interface.

---

## ✨ Features

- 🎯 Predict student performance instantly
- 📊 Interactive and user-friendly web interface
- 🤖 Machine Learning-based prediction model
- ⚡ Fast and lightweight application
- 📱 Responsive Streamlit interface
- 🚀 Real-time prediction results

---

## 📥 Input Parameters

The prediction model uses the following academic inputs:

- 📚 Study Hours
- 🏫 Attendance Percentage
- 📝 Previous Marks

---

## 📤 Output

The application predicts:

- 📈 Estimated Student Performance Score

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/2403a52007/Student-Performance-Ai.git
cd Student-Performance-Ai
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```
